# Instrukcja Maker

Mały, lokalny generator czytelnych instrukcji krok po kroku.

## Funkcje prototypu

- edycja tytułu i opisu,
- kroki instrukcji,
- zmiana kolejności kroków,
- zdjęcia PNG/JPG/WebP,
- automatyczne dopasowanie zdjęć do strony,
- podpisy zdjęć,
- wskazówki / uwagi / informacje / ważne,
- podgląd A4,
- drukowanie przez przeglądarkę,
- automatyczny zapis w localStorage.
